# Referencias Telemoji para el compositor

Las siguientes páginas fueron compartidas por el usuario como guía visual y semántica. El compositor elige el glifo Unicode según el tono del mensaje y, cuando existe, lo dibuja con un fotograma local de Telemoji de Telegram. Para los pocos símbolos sin Telemoji disponible, conserva Twemoji como alternativa documentada en `twemoji/ATTRIBUTION.md`.
