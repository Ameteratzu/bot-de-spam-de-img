# Telegram animated emoji frames

These local PNGs are the first frames of Telegram animated emoji, rasterized for static chat-image output. The source package is [saeedtahmtan/telemoji](https://github.com/saeedtahmtan/telemoji), which credits the original animations to Telegram.

This project uses the artwork as a local visual reference for its chat compositor. Telegram retains rights to its Telemoji artwork; follow Telegram's terms for any distribution or commercial use.

Prepared assets: 1F916, 1F4C8, 1F680, 1F4B0, 1F389, 1F64C, 1F4AA, 1F3C6, 1F525, 1F4C9, 1F4DD, 1F4A1, 1F64F, 2728, 1F31F, 1F4B8, 1F44F, 1F620, 1F92A, 1F92F, 1F978, 1F913, 1F929, 1F911, 1F608, 1F973, 1F633.

Not present in the source package: 1F4B5, 1F9E0, 1F3AF, 1F4B9.
